# Release 0.1.0 — First public milestone

## Status

Release candidate prepared on 2026-08-06. Publication, tagging, and artifact
upload require explicit maintainer approval and are not performed by this
repository preparation work.

## Version decision

0.1.0 is the first public milestone because the project is intentionally
pre-1.0, has a completed, bounded public contract, and has no existing Git
tag or historical release reference for `v0.1.0` or an equivalent version.
The version is not 1.0.0: the project remains a learning laboratory with
deliberately limited claims and an evolving public surface.

The authoritative source version is `0.1.0` in `pyproject.toml`; the package
`__version__`, installed distribution metadata, and analysis-manifest project
version must match it. Release-contract tests prevent drift between these
surfaces.

## Included contract

- Deterministic file-based analysis from exact JSON Lines bytes.
- Deterministic plain-language summaries derived only from structured
  analysis results, without diagnostic or security conclusions.
- Experiment 001 and its byte-for-byte synthetic report fixtures.
- Structured two-window comparison and deterministic Markdown reporting.
- Installed `analyze` and `compare` commands.
- Privacy-safe, bounded, local-only `collect` acquisition.

All results are descriptive. They do not claim randomness, compromise,
malicious behaviour, safety, user intent, or administrator intent.

## Dependency provenance decision

Digit-Probe has a public `v0.1.0` release at commit
`86867d600fb8c8836bed43b7543270d6ffd93aa8`, but it is not suitable for this milestone. That release
predates the packaged public API used by System Log Dynamics: its
`pyproject.toml` has no `[project]` package metadata, while the selected commit
is fourteen commits ahead and declares Digit-Probe version `1.0.0`.

Digit-Probe therefore remains pinned to immutable full commit
`55e3eae4c55017703e023c1aaac0838b873482db` from its canonical repository rather than being replaced with the
older release, a branch, or a floating version range. Analysis manifests
record the commit from installed dependency metadata, preserving the
provenance of every analyzed window.

## Release material

The source distribution and wheel include the changelog, this release note,
the release process, architecture decisions, Experiment 001 documentation,
synthetic JSON Lines fixtures, and reviewed Markdown report fixtures. They do
not include real journal data or generated build output.
